## Méthodes classiques de Machine Learning

Cette section couvre les **algorithmes fondamentaux** qui constituent la base de tout projet de Machine Learning.  
On y retrouve les régressions, méthodes bayésiennes, SVM, k-NN et les arbres décisionnels.  
Ces méthodes sont souvent utilisées pour les **données tabulaires**, les **prédictions supervisées** et les benchmarks rapides.  
Les ensembles (Random Forests, Gradient Boosting) permettent d’améliorer la robustesse et la performance sur des problèmes complexes.
