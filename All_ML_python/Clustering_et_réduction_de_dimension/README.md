## Clustering et réduction de dimension

Ces techniques permettent de **regrouper des données similaires** ou de **réduire la complexité des données** tout en conservant leur structure essentielle.  
Clustering : k-Means, DBSCAN, Spectral Clustering pour identifier des patterns non étiquetés.  
Réduction de dimension : PCA, t-SNE, UMAP, Autoencoders pour visualisation, compression ou prétraitement de données volumineuses.
