## Apprentissage par renforcement

Cette catégorie regroupe les méthodes permettant à un agent d’**apprendre par interaction avec un environnement**.  
On y trouve Q-Learning, DQN, Policy Gradient, Actor-Critic et les variantes avancées (PPO, TRPO, SAC, DDPG).  
Applications : robotique, jeux, optimisation de processus, multi-agent systems.  
Meta-RL et techniques multi-agent permettent des stratégies adaptatives et transférables.
