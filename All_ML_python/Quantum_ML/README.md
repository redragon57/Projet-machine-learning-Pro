## Apprentissage quantique (Quantum Machine Learning - QML)

Les méthodes QML exploitent la **superposition et l’intrication quantique** pour traiter certains problèmes plus efficacement qu’en classique :  
- QSVM, Quantum k-Means, Quantum Boltzmann Machines  
- Variational Quantum Circuits et Quantum Neural Networks  
- Modèles hybrides classique-quantique  
- Applications : optimisation combinatoire, simulation moléculaire et chimie quantique  
Cette section prépare à l’intégration des technologies quantiques dans les pipelines de ML.
