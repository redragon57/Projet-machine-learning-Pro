## Apprentissage avancé et hybrides

Ici sont listées les méthodes **d’apprentissage avancées**, combinant plusieurs paradigmes ou spécialisées pour l’apprentissage sur le long terme.  
- Few-shot, Zero-shot learning pour généralisation rapide  
- Meta-learning (MAML, Reptile, LEAP) pour transfert de connaissances  
- Continual / Lifelong Learning (EWC, GEM, AGEM, Progressive Neural Networks)  
- NAS et AutoML pour conception automatisée de modèles  
- Neuroevolution (NEAT) et Genetic Programming pour optimisation structurelle et évolutive  
- Systèmes de plasticité structurelle et hybridation neuro-symbolique
