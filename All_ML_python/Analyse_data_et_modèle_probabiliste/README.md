## Analyse de données et modèles probabilistes

Cette section inclut les outils d’**analyse statistique avancée**, séries temporelles et modèles probabilistes :  
- ARIMA, SARIMA, Prophet pour séries temporelles  
- Méthodes de causalité (Granger, DoWhy)  
- Graph Mining et Graph Neural Networks (GNN, GraphSAGE, GAT)  
- Méthodes bayésiennes hiérarchiques, Approximate Bayesian Computation  
- Simulation Monte Carlo, MCMC et Variational Inference  
Ces techniques permettent d’extraire des patterns, de modéliser l’incertitude et de réaliser des simulations complexes.
